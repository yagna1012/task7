# Task 7 – Sales Data Analysis Using SQLite and Python

## 📌 Project Overview
This project demonstrates how to use SQLite with Python to store sales data, execute SQL queries, and visualize the results using a bar chart.  
It is designed for beginners to understand basic database operations and data analysis.

---

## 🎯 Objective
- Create a SQLite database  
- Store sales data in a table  
- Execute SQL queries using Python  
- Calculate total quantity and revenue per product  
- Display results in tabular format  
- Visualize revenue using a bar chart  

---

## 🛠 Technologies Used
- Python  
- SQLite (sqlite3)  
- Pandas  
- Matplotlib  
- Google Colab / Jupyter Notebook
